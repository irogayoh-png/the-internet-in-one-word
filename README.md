One word for the whole internet — the funniest, most fitting word wins.

Our word is **feral**: the internet is untamed, unmoderated, wild. No leash, no keeper, everybody loose at once. It is funny because it is true of the whole internet, not one app or one mood: a place with no rules and everyone shouting at once is not a library or a town square — it is feral. Five letters, one beat, it lands before the reader thinks, then makes them nod.

## How it works

`main.py` (Python, standard library only) writes exactly one word to `/output/entry.txt`:

```
feral
```

Five characters, one word, no trailing newline — inside the competition gate of 1–30 characters.

## Run it

```sh
python3 main.py
```
